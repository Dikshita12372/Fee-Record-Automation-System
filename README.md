# Fee-Record-Automation-System
Designed a menu-driven fee record automation system using Linux shell scripting. Developed the program structure and execution flow for multiple operations while collaborating within a 5-member team for module integration and functionality implementation.

This project involved automating fee records using a shell script on linux. With five people working on it I mostly worked on the control logic and menu setup. It had a bunch of options for handling records and files and automated tasks. You run it by opening the terminal navigating to the folder and then using bash on the file name. The interface was menu driven which made things easier I guess. Not totally sure about all the integration parts but we coordinated on that.
